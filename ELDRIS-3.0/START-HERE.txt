ELDRIS 3.0 — how to run and publish this download
==================================================

A. Open the dashboard on this computer (about 2 minutes)
--------------------------------------------------------
1. Install Python 3.10+ (Node.js is NOT needed: frontend/dist is already built).
2. Open a terminal in this folder and run:

     cd backend
     python -m venv .venv
     .venv\Scripts\activate        (Windows)
     source .venv/bin/activate     (macOS / Linux)
     pip install -r requirements.txt
     copy .env.example .env        (Windows; use cp on macOS/Linux)
     python app.py

3. Open http://127.0.0.1:5000 — the dashboard opens as a guest, no login needed.

B. Publish it for free (public HTTPS link, no account)
------------------------------------------------------
From the top folder, run:

     publish-free.cmd              (Windows: double-click or run it)
     ./publish-free.sh             (macOS / Linux)

The script installs the backend, starts it, downloads the free Cloudflare
tunnel client once, and prints an address like:

     https://something-random.trycloudflare.com

Open that on any phone or laptop. It prints the exact API_URL and
DEVICE_API_KEY to paste into the band sketch. Keep the window open while it is
published. The address is new each run.

For a permanent URL (Render free plan) and for the named-tunnel option, read
docs/DEPLOY-FREE.md.

C. Connect the wrist band
-------------------------
You do NOT need the ESP32's IP address. The band connects outward to the server.

Edit hardware/esp32_hand_band/esp32_hand_band.ino:

     static const char *WIFI_SSID      = "your-wifi";
     static const char *WIFI_PASSWORD   = "your-password";
     static const char *API_URL         = "https://your-address/api/motion";
     static const char *DEVICE_API_KEY  = "same value as on the server";

Flash it, then open the serial monitor at 115200 baud. One ESP32 reports all of
it: tremor and fall (MPU6050), heart rate and SpO2 (MAX30102), body temperature
(MLX90614). Detection runs on the server, so thresholds live in backend/.env.

The second sketch, hardware/esp32_home_climate/esp32_home_climate.ino, is the
single home temperature/humidity sensor (DHT22). Same API_URL pattern.

D. Where the money and the limits are
-------------------------------------
- Tunnel option: free, no account, but your computer must stay awake and the
  address changes per run.
- Render free option: permanent address, no computer needed, but it sleeps
  after 15 idle minutes and has no disk, so accounts/reminders reset on restart.
- Cameras and robot motor control are LAN-only by design. Never expose motor
  control on the public internet.
